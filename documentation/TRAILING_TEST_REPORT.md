## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Архитектура трейлинга:
- **PnL-based система**: Основана на абсолютной прибыли в USDT
- **Уровневая защита**: 4 уровня с возрастающей защитой
- **Монотонность**: Peak и SL никогда не ухудшаются

### Алгоритм обновления:
1. Проверка превышения порога активации
2. Обновление максимального PnL (только улучшение)
3. Определение уровня по максимальному PnL
4. Расчет целевой прибыли для сохранения  
5. Обновление SL (только улучшение)

### Отладочная информация:
- Текущий уровень трейлинга
- Процент сохранения прибыли
- Флаг обновления SL
- Старые и новые значения
