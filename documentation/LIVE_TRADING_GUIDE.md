## ⚙️ **НАСТРОЙКА ОКРУЖЕНИЯ**

### 1. **API Ключи Binance**

Создайте файл `.env`:
```bash
BINANCE_API_KEY=your_api_key_here
BINANCE_SECRET=your_secret_here
HTTP_PROXY=
HTTPS_PROXY=
```

**Настройки API ключа:**
- ✅ **Futures Trading** - обязательно
- ❌ **Spot Trading** - не нужно
- ❌ **Margin Trading** - не нужно
- ❌ **Withdrawals** - НИКОГДА не включайте!

### 2. **Конфигурация производства**

Основные параметры в `config_production.yaml`:

```yaml
# РЕЖИМ ТОРГОВЛИ
exchange:
  testnet: true    # false для live торговли

# РИСК-МЕНЕДЖМЕНТ
risk:
  margin_usdt: 15  # $15 маржи на сделку
  leverage: 5      # 5x плечо = $75 номинал
  sl_atr_mult: 1.5 # Стоп на 1.5x ATR

# АДАПТИВНЫЕ ШОРТЫ
short_guard:
  rsi_bear_max: 52      # В медвежьем рынке
  rsi_bullcorr_max: 50  # В бычьих коррекциях
  min_natr_bear: 0.9    # Минимальная волатильность
```

## 🎯 **СТРАТЕГИЯ v1.6-TXB**

### **Multi-Timeframe (MTF) подход:**
- **1h Breakout** - основные качественные сигналы
- **15m LTF setups** - Inside-bar, Trend-continuation, Squeeze
- **BTC Market Filter** - контекст для направления

### **Адаптивные шорты:**
- **Медвежий рынок BTC**: строгие условия (RSI≤52, NATR≥0.9%)
- **Бычьи коррекции**: мягче (RSI≤50, NATR≥0.8%, close<EMA20)
- **Ассиметричные ATR подушки** - шире для шортов

### **Profit-First трейлинг:**
- **BE@0.35R + 0.08R offset** - быстрый переход в безубыток
- **Chandelier 3.5x ATR** - удержание трендов
- **R-step 0.20** - плавные подтяжки
