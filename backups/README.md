# 💾 Резервные копии

Эта папка содержит все резервные копии и исторические данные проекта SignalWarden Lite v1.6-TXB.

## 📁 Содержимое

### Отчеты бэктестов
- `backtest_report*.csv` - Отчеты бэктестов различных версий
- `backtest_trades*.csv` - Детальные данные сделок бэктестов

### Состояние системы
- `trading_state*.json` - Состояние торговой системы
- `trading_state_*_backup_*.json` - Резервные копии состояния
- `trading_state_*.json.corrupted.backup.*` - Испорченные файлы состояния

### Кэш и временные файлы
- `cache_control_signal.json` - Кэш сигналов
- `test_storage.json.corrupted.*` - Испорченные файлы хранилища

## ⚠️ Важно

- Эти файлы не нужны для работы основной системы
- Они сохранены для исторических целей и анализа
- При необходимости можно удалить старые файлы

## 🔄 Восстановление

Если нужно восстановить состояние системы из резервной копии:

```bash
# Восстановить состояние системы
cp backups/trading_state_v1_6_TXB_backup_YYYYMMDD_HHMMSS.json ../trading_state_v1_6_TXB.json
```

## 📊 Анализ

Для анализа исторических данных используйте соответствующие CSV файлы с результатами бэктестов.
