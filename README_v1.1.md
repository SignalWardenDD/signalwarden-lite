## 🔍 Ключевые находки

### 💡 Что работает
- **Breakout сетап**: 100% всех сделок, основа системы
- **Динамические lookback**: адаптация к режимам рынка
- **LONG позиции**: 77.2% винрейт, +27.77 USDT
- **Увеличенный ATR cushion**: 0.28 в calm режиме

- **Inside-bar сетап**: 0 сделок на исторических данных

- **SHORT позиции**: хуже LONG (66% WR vs 77%)

## 🚀 Рекомендации для продакшена

### 1. Оптимальная конфигурация
```yaml
symbols: [ADA_USDT, LTC_USDT, WIF_USDT]  # Только топ-3
risk:
  notional_usdt: 15                        # Или снизить до 10
cutloss_early:
  enabled: false                           # ОТКЛЮЧИТЬ!
setups:
  breakout: {enabled: true}                # Основной сетап
  pullback: {enabled: false}               # Отключить
  inside_bar: {enabled: false}             # Отключить
```

### 2. Ожидаемые результаты (топ-3 пары)
- **57 сделок/месяц** (при 200 барах данных)
- **+45 USDT прибыль** за период
- **PF > 3.0** в среднем
- **78% винрейт** в среднем

### 3. Мониторинг
- Отслеживать только ADA, LTC, WIF
- Винрейт должен быть > 70%
- PF должен быть > 2.0
- При ухудшении - пересмотреть параметры

## 🔧 Установка и запуск v1.1

### Бэктест
```bash
python -m signalwarden_lite.backtest.run_backtest \
  --data-dir ./data/historical_candles \
  --config ./signalwarden_lite/config/config_optimized.yaml
```

### Live Trading
```bash
# Paper trading
python -m signalwarden_lite.live.run_live \
  --config ./signalwarden_lite/config/config_optimized.yaml --paper

# Live trading (осторожно!)
python -m signalwarden_lite.live.run_live \
  --config ./signalwarden_lite/config/config_optimized.yaml
```
