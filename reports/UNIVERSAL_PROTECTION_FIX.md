**Критическая ошибка:** DOGE позиции закрывались с PnL $0 и $0.02 вместо минимальных $0.03

## 🔍 АНАЛИЗ ПРИЧИНЫ

### Что происходило:
1. **Защита работала только при активации трейлинга** (PnL ≥ $0.06)
2. **Для новых позиций защита НЕ применялась** (до активации трейлинга)
3. **Позиции закрывались по обычному SL** с PnL < $0.03

### Корень проблемы:
**Защита была внутри блока `if keep_pct > 0:`** - это означало, что она применялась только при активации трейлинга!

```python
# НЕПРАВИЛЬНО (было):
if keep_pct > 0:  # Только при активации трейлинга
    # ЗАЩИТА ТРЕЙЛИНГА: Минимальный SL $0.03
    min_profit_usdt = 0.03
    min_sl = pos.entry + (min_profit_usdt / pos.qty)
    # ... защита применялась только здесь
```

**Результат:** Новые позиции (до активации трейлинга) НЕ получали защиту!

## ✅ ИСПРАВЛЕНИЕ

### Универсальная защита для ВСЕХ позиций:

```python
# ПРАВИЛЬНО (стало):
# УНИВЕРСАЛЬНАЯ ЗАЩИТА: Минимальный SL $0.03 для ВСЕХ позиций
min_profit_usdt = 0.03  # Минимальная прибыль $0.03
min_sl = pos.entry + (min_profit_usdt / pos.qty)  # Минимальный SL для LONG

if keep_pct > 0:
    # Трейлинг активен - применяем полную защиту
    pnl_sl = pos.entry + (target_profit / pos.qty)
    protected_sl = max(pnl_sl, min_sl)  # Лучший из двух
    # ...
else:
    # Трейлинг НЕ активен - применяем только базовую защиту
    if min_sl > pos.sl:
        pos.sl = min_sl  # Устанавливаем минимальный SL $0.03
```

### Логика работы:

1. **Для ВСЕХ позиций** рассчитывается минимальный SL с PnL = $0.03
2. **Если трейлинг активен** - используется лучший из трейлинг SL и минимального SL
3. **Если трейлинг НЕ активен** - применяется только минимальный SL $0.03
4. **Гарантия:** Никакая позиция не может закрыться с PnL < $0.03
