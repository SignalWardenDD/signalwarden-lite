**Критическая ошибка:** L4 уровень имел предел роста - SL не улучшался после достижения максимального PnL

## 🔍 НАСТОЯЩАЯ ПРИЧИНА

### Что было неправильно:

```python
# НЕПРАВИЛЬНО (было для всех уровней):
target_profit = current_pnl_usdt * keep_pct  # ❌ Неправильно для L4!

# ПРАВИЛЬНО (стало):
if level_name == "L4":
    target_profit = pos.peak_pnl_usdt * keep_pct  # ✅ Правильно для L4!
else:
    target_profit = current_pnl_usdt * keep_pct  # ✅ Правильно для L1-L3!
```

### Объяснение ошибки:

**Неправильно:**
- Для L4 уровня использовался `current_pnl_usdt` - это означало, что SL не улучшался после достижения максимального PnL
- Если позиция достигла $0.50 PnL, то SL всегда был на уровне 80% от $0.50 = $0.40
- При падении PnL до $0.45, SL тоже падал до 80% от $0.45 = $0.36

**Правильно:**
- Для L4 уровня используется `pos.peak_pnl_usdt` - это означает, что SL сохраняет 80% от максимального PnL
- Если позиция достигла $0.50 PnL, то SL всегда будет на уровне 80% от $0.50 = $0.40
- При падении PnL до $0.45, SL остается на уровне $0.40 (80% от максимального $0.50)
