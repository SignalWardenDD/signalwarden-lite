# 🚀 ИСПРАВЛЕНИЕ ТРЕЙЛИНГА - РОСТ ВНУТРИ УРОВНЕЙ

## 📊 ПРОБЛЕМА
**Дата:** 11 сентября 2025, 22:15 UTC  
**Критическая ошибка:** Трейлинг НЕ РАСТЕТ внутри уровней - SL не улучшается по мере роста PnL

## 🔍 НАСТОЯЩАЯ ПРИЧИНА

### Что было неправильно:

```python
# НЕПРАВИЛЬНО (было):
target_profit = pos.peak_pnl_usdt * keep_pct  # ❌ Неправильно!

# ПРАВИЛЬНО (стало):
target_profit = current_pnl_usdt * keep_pct  # ✅ Правильно!
```

### Объяснение ошибки:

**Неправильно:**
- `pos.peak_pnl_usdt * keep_pct` - SL рассчитывается на основе **МАКСИМАЛЬНОГО** PnL
- Это означает, что SL **НЕ РАСТЕТ** внутри уровня!
- Если позиция достигла $0.08 PnL, то SL всегда будет на уровне 50% от $0.08 = $0.04

**Правильно:**
- `current_pnl_usdt * keep_pct` - SL рассчитывается на основе **ТЕКУЩЕГО** PnL
- Это означает, что SL **РАСТЕТ** внутри уровня!
- Если позиция имеет $0.07 PnL, то SL будет 50% от $0.07 = $0.035
- Если позиция растет до $0.08 PnL, то SL улучшается до 50% от $0.08 = $0.04

## ✅ ИСПРАВЛЕНИЕ


## 🔧 Техническая реализация

### Исправленный код для LONG:

```python
if keep_pct > 0:
    # КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: SL должен РАСТИ внутри уровня!
    # Рассчитываем новый SL на основе ТЕКУЩЕГО PnL, а не максимального
    # Это означает, что SL улучшается по мере роста PnL внутри уровня
    target_profit = current_pnl_usdt * keep_pct
    # КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: SL должен быть на уровне entry + сохраненная прибыль на единицу
    # Для LONG: (SL - entry) * qty = target_profit, поэтому SL = entry + (target_profit / qty)
    pnl_sl = pos.entry + (target_profit / pos.qty)
    
    # ЗАЩИТА: Используем максимальный из рассчитанного SL и минимального защитного SL
    protected_sl = max(pnl_sl, min_sl)
    
    if protected_sl > pos.sl:
        pos.sl = protected_sl
```

### Исправленный код для SHORT:

```python
if keep_pct > 0:
    # КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: SL должен РАСТИ внутри уровня!
    # Рассчитываем новый SL на основе ТЕКУЩЕГО PnL, а не максимального
    # Это означает, что SL улучшается по мере роста PnL внутри уровня
    target_profit = current_pnl_usdt * keep_pct
    # КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: SL должен быть на уровне entry - сохраненная прибыль на единицу
    # Для SHORT: (entry - SL) * qty = target_profit, поэтому SL = entry - (target_profit / qty)
    pnl_sl = pos.entry - (target_profit / pos.qty)
    
    # ЗАЩИТА: Используем минимальный из рассчитанного SL и максимального защитного SL
    protected_sl = min(pnl_sl, min_sl)
    
    if protected_sl < pos.sl:
        pos.sl = protected_sl
```
