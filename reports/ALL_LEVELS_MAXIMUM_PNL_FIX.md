## 🔍 НАСТОЯЩАЯ ПРИЧИНА

### Что было неправильно:

```python
# НЕПРАВИЛЬНО (было):
if level_name == "L4":
    target_profit = pos.peak_pnl_usdt * keep_pct  # ✅ Только L4
else:
    target_profit = current_pnl_usdt * keep_pct  # ❌ L1-L3 использовали текущий PnL

# ПРАВИЛЬНО (стало):
# ВСЕ уровни используют МАКСИМАЛЬНЫЙ PnL!
target_profit = pos.peak_pnl_usdt * keep_pct  # ✅ Все уровни
```

### Объяснение ошибки:

**Неправильно:**
- Только L4 уровень использовал максимальный PnL
- L1-L3 уровни использовали текущий PnL - это означало, что SL мог ухудшаться
- При падении PnL внутри уровня, SL тоже падал

**Правильно:**
- ВСЕ уровни используют максимальный PnL
- SL всегда растет и никогда не ухудшается
- При падении PnL внутри уровня, SL остается на максимальном уровне

## 🔧 Техническая реализация

### Исправленный код для LONG:

```python
if keep_pct > 0:
    # ЗАЩИТА $0.03: Минимальный SL $0.03 при активации трейлинга
    min_profit_usdt = 0.03
    min_sl = pos.entry + (min_profit_usdt / pos.qty)
    
    # КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: ВСЕ уровни используют МАКСИМАЛЬНЫЙ PnL!
    # Это означает, что SL всегда растет и никогда не падает внутри уровня
    target_profit = pos.peak_pnl_usdt * keep_pct
    
    # Рассчитываем SL
    pnl_sl = pos.entry + (target_profit / pos.qty)
    
    # ЗАЩИТА: Используем максимальный из рассчитанного SL и минимального защитного SL
    protected_sl = max(pnl_sl, min_sl)
    
    if protected_sl > pos.sl:
        pos.sl = protected_sl
```

