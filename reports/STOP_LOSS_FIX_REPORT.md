# 🚨 ИСПРАВЛЕНИЕ ПРОБЛЕМЫ "ORDER WOULD IMMEDIATELY TRIGGER"

## 📋 ПРОБЛЕМА
Система показывала ошибки при создании стоп-лосс ордеров:
```
❌ HBAR_USDT: Failed to create stop-loss: binanceusdm {"code":-2021,"msg":"Order would immediately trigger."}
❌ HBAR_USDT: КРИТИЧНО - НЕ УДАЛОСЬ СОЗДАТЬ SL ОРДЕР!
❌ HBAR_USDT: ПОЗИЦИЯ НЕ БУДЕТ ДОБАВЛЕНА В ТРЕЙЛИНГ!
🛡️ HBAR_USDT: Позиция закрыта для безопасности
```

## 🔍 АНАЛИЗ ПРОБЛЕМЫ

### Причина ошибки:
- **Стоп-лосс слишком близко к текущей цене**
- **Binance требует минимальную дистанцию** между текущей ценой и стоп-лоссом
- **Отсутствие валидации дистанции** в коде

### Пример из логов:
- Текущая цена HBAR: $0.240270
- Расчетный стоп-лосс: $0.240522 
- **Проблема**: SL выше текущей цены для LONG позиции!

## 🔧 РЕАЛИЗОВАННОЕ ИСПРАВЛЕНИЕ

### Файл: `signalwarden_lite/core/execution.py`

#### 1. Добавлена валидация дистанции:
```python
# Get current price for validation
ticker = self.exchange.fetch_ticker(ccxt_symbol)
current_price = ticker['last']

# Calculate distance from current price
if side == 'LONG':
    distance_pct = abs(current_price - stop_price) / current_price * 100
    min_distance_pct = 0.5  # Minimum 0.5% distance for LONG
else:
    distance_pct = abs(stop_price - current_price) / current_price * 100
    min_distance_pct = 0.5  # Minimum 0.5% distance for SHORT
```

#### 2. Автоматическая корректировка:
```python
# Validate minimum distance
if distance_pct < min_distance_pct:
    if side == 'LONG':
        adjusted_stop = current_price * (1 - min_distance_pct / 100)
    else:
        adjusted_stop = current_price * (1 + min_distance_pct / 100)
    
    logger.warning(f"⚠️ {symbol}: SL слишком близко к цене!")
    logger.warning(f"   Корректировка SL: {stop_price:.6f} → {adjusted_stop:.6f}")
    stop_price = adjusted_stop
```
