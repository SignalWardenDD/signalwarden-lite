# 🚨 КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: Активация трейлинга

## Проблема
Пользователь сообщил: **"Трейлинг не активируется для позиций что проходят порог. Это критично"**

### Анализ проблемы
Из логов ADA_USDT было обнаружено:
1. ✅ **Трейлинг активировался правильно**: `PnL-трейлинг активен - Уровень: L1, Peak PnL: $0.0666`
2. ✅ **SL был рассчитан правильно**: `SL УЛУЧШЕНИЕ для LONG: 0.926782 → 0.953273`
3. ❌ **НО**: `TRAILING SL WOULD TRIGGER IMMEDIATELY! Current: 0.932100, New SL: 0.953273`
4. ❌ **Результат**: `КРИТИЧНО - не удалось создать TRAILING SL после всех попыток!`
5. ❌ **Позиция закрылась с убытком**: `-0.44 USDT` вместо защиты минимальной прибыли `$0.03`

### Корневая причина
**SL был рассчитан выше текущей цены**, что означало, что ордер сработал бы немедленно. Это происходило потому, что:
- Трейлинг рассчитывает SL на основе **пикового PnL** ($0.0666)
- К моменту создания ордера цена уже упала (0.932100)
- Новый SL (0.953273) был **выше** текущей цены (0.932100)

## Решение

### 1. Защита от SL выше/ниже текущей цены
Добавлена логика в `signalwarden_lite/core/trailing_pnl_only.py`:

#### Для LONG позиций:
```python
# ДОПОЛНИТЕЛЬНАЯ ЗАЩИТА: SL не должен быть выше текущей цены (hi)
if protected_sl > pos.sl and protected_sl < hi:
    pos.sl = protected_sl
    # ... обновление SL
elif protected_sl >= hi:
    # КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: SL выше текущей цены - используем цену с буфером
    safe_sl = hi * 0.999  # 0.1% буфер ниже текущей цены
    if safe_sl > pos.sl:
        pos.sl = safe_sl
        pos.trailing_debug['price_protection'] = True
        logger.warning(f"🚨 PnL-трейлинг: SL {protected_sl:.6f} выше цены {hi:.6f}! Используем безопасный SL {safe_sl:.6f}")
```

#### Для SHORT позиций:
```python
# ДОПОЛНИТЕЛЬНАЯ ЗАЩИТА: SL не должен быть ниже текущей цены (lo)
if protected_sl < pos.sl and protected_sl > lo:
    pos.sl = protected_sl
    # ... обновление SL
elif protected_sl <= lo:
    # КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: SL ниже текущей цены - используем цену с буфером
    safe_sl = lo * 1.001  # 0.1% буфер выше текущей цены
    if safe_sl < pos.sl:
        pos.sl = safe_sl
        pos.trailing_debug['price_protection'] = True
        logger.warning(f"🚨 PnL-трейлинг SHORT: SL {protected_sl:.6f} ниже цены {lo:.6f}! Используем безопасный SL {safe_sl:.6f}")
```

### 2. Тестирование исправлений
Создан комплексный тест `scripts/test_trailing_activation_fix.py`:

#### ✅ Тест 1: Нормальная активация трейлинга
- PnL $0.07 (выше порога $0.06)
- Трейлинг активируется на уровне L1
- SL обновляется для защиты прибыли

#### ✅ Тест 2: Защита от SL выше текущей цены
- Пиковый PnL $0.50, текущая цена упала
- SL рассчитан выше цены → активируется защита
- Используется безопасный SL с буфером 0.1%

#### ✅ Тест 3: SHORT позиция с защитой
- Аналогичная защита для SHORT позиций
- SL не может быть ниже текущей цены

#### ✅ Тест 4: Минимальная защита $0.03
- При PnL $0.06 (порог активации)
- Гарантируется минимальная прибыль $0.03
