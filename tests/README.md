# 🧪 Тесты и проверки

Эта папка содержит все тестовые скрипты и проверки системы SignalWarden Lite v1.6-TXB.

## 📁 Содержимое

### Анализ системы
- `analyze_*.py` - Анализ различных аспектов системы
- `check_*.py` - Проверки текущего состояния
- `debug_*.py` - Отладочные скрипты
- `final_system_analysis.py` - Финальный анализ системы

### Тесты
- `test_*.py` - Различные тесты системы
- `test_system_scenarios.py` - Тесты в различных рыночных условиях
- `test_real_market_scenarios.py` - Тесты на реальных данных

### Утилиты
- `diagnose_*.py` - Диагностические скрипты
- `emergency_*.py` - Экстренные утилиты
- `fix_*.py` - Скрипты исправления
- `monitor_*.py` - Мониторинг системы

### Бэктесты
- `run_backtest_*.py` - Скрипты запуска бэктестов
- `run_production_*.py` - Production бэктесты

## 🚀 Запуск тестов

```bash
# Анализ текущего состояния системы
python tests/final_system_analysis.py

# Тесты в различных сценариях
python tests/test_system_scenarios.py

# Тесты на реальных данных
python tests/test_real_market_scenarios.py
```

## ⚠️ Примечание

Эти скрипты предназначены для тестирования и отладки. Не используйте их в production без понимания их назначения.
