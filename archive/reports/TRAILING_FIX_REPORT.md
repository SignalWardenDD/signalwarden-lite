## 🔍 АНАЛИЗ ПРОБЛЕМЫ

### Причина
Неправильная логика расчета Stop-Loss в функции `update_trailing_pnl_only`:

**НЕПРАВИЛЬНО (было):**
```python
# Для LONG позиций
pnl_sl = pos.entry + target_profit  # ❌ Неправильно!

# Для SHORT позиций  
pnl_sl = pos.entry - target_profit  # ❌ Неправильно!
```

**ПРАВИЛЬНО (стало):**
```python
# Для LONG позиций
pnl_sl = pos.entry + (target_profit / pos.qty)  # ✅ Правильно!

# Для SHORT позиций
pnl_sl = pos.entry - (target_profit / pos.qty)  # ✅ Правильно!
```

### Объяснение
- `target_profit` - это общая прибыль в долларах для всей позиции
- `pos.qty` - количество единиц в позиции
- `target_profit / pos.qty` - прибыль на единицу, которую нужно добавить к entry для получения правильного SL
