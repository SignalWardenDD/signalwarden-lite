## 📊 ПРОБЛЕМА
**Дата:** 11 сентября 2025, 21:09 UTC  
**Критическая ошибка:** DOGE позиция закрылась с PnL $0 вместо правильного трейлинг SL

## 🔍 АНАЛИЗ ПРИЧИНЫ

### Что происходило:
1. **Трейлинг работал правильно** - рассчитывал корректный SL
2. **НО!** Было **дублирующееся создание stop-market ордеров**
3. **Конфликт ордеров** приводил к неправильному исполнению

### Корень проблемы:
В функции `update_trailing_stops()` было **два места** создания stop-market ордеров:

**МЕСТО 1** (строка 794):
```python
self.update_sliding_stop_loss(symbol, pos)  # Правильный ордер
```

**МЕСТО 2** (строки 796-825):
```python
# ДУБЛИРУЮЩИЙСЯ КОД - создавал второй ордер!
new_sl_order = self.exchange.create_order(
    ccxt_sym,
    'stop_market',
    sl_side,
    pos['qty'],
    None,
    params={
        'stopPrice': updated_pos.sl,  # Правильный SL
        'reduceOnly': True,
        'timeInForce': 'GTC'
    }
)
```

### Последовательность ошибки:
1. **Трейлинг активируется** при PnL ≥ $0.06
2. **Новый SL рассчитывается** правильно (например, $0.251465)
3. **`pos['sl_current']` обновляется** правильно
4. **Первый ордер создается** с правильным SL через `update_sliding_stop_loss`
5. **Второй ордер создается** дублирующимся кодом ❌
6. **Конфликт ордеров** или **перезапись** приводит к неправильному исполнению

## ✅ ИСПРАВЛЕНИЕ

### Удален дублирующийся код:
```python
# БЫЛО (НЕПРАВИЛЬНО):
self.update_sliding_stop_loss(symbol, pos)  # Правильный ордер

# ДУБЛИРУЮЩИЙСЯ КОД - УДАЛЕН!
try:
    ccxt_sym = self.ccxt_symbol(symbol)
    sl_side = 'sell' if pos['side'] == 'LONG' else 'buy'
    
    # Отменяем старые SL ордера
    # ... код отмены ...
    
    # Создаем новый stop-market ордер с обновленным SL
    new_sl_order = self.exchange.create_order(...)  # ДУБЛИРУЮЩИЙСЯ!
except Exception as e:
    logger.error(f"❌ {symbol}: Ошибка создания stop-market ордера при трейлинге: {e}")

# СТАЛО (ПРАВИЛЬНО):
self.update_sliding_stop_loss(symbol, pos)  # Только один ордер
```

- ❌ Конфликт ордеров приводил к неправильному исполнению
- ❌ Позиции закрывались с PnL ~$0 вместо правильного трейлинг SL

### После исправления:
