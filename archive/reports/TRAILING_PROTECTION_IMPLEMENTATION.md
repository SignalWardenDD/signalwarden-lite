**Принцип работы:**
1. **При активации трейлинга** (PnL ≥ $0.06) рассчитывается обычный SL
2. **Защита проверяет**: если обычный SL дает PnL < $0.03, то устанавливается минимальный SL с PnL = $0.03
3. **При росте PnL** используется обычная логика трейлинга
4. **Минимальный SL фиксированный** - всегда обеспечивает PnL ≥ $0.03

#### Для LONG позиций:

