## 📊 Мониторинг в реальном времени

### **Что отслеживается:**
- 💰 **Баланс USDT** - каждую минуту
- 📈 **Активные позиции** - каждые 30 секунд
- 🔍 **Консистентность состояния** - каждые 2 минуты

- 🚨 **КРИТИЧЕСКИЕ** - недостаток средств, повреждение файлов

- 🔶 **СРЕДНИЕ** - высокое использование маржи, блокировка сигналов

### **Файлы мониторинга:**
- `monitoring_alerts.json` - история всех алертов
- `system_audit_report.json` - отчеты аудита
- `final_test_results.json` - результаты тестирования

## 🛡️ Предотвращение проблем

### **Резервные копии:**
- Автоматически создаются перед каждым исправлением
- Формат: `trading_state_v1_6_TXB.json.backup.YYYYMMDD_HHMMSS`
- Сохраняются в корне проекта

### **Валидация:**
- Проверка структуры файла состояния
- Валидация данных позиций
- Синхронизация с биржей
- Проверка логики стоп-лоссов

### **Автоисправление:**
- Удаление призрачных позиций
- Синхронизация отсутствующих позиций
- Исправление несоответствий
- Восстановление поврежденных файлов

## 🔍 Диагностика проблем

### **Если система не открывает позиции:**
1. Запустите аудит: `python tests/comprehensive_system_audit.py`
2. Проверьте алерты: `cat monitoring_alerts.json`
3. Запустите автоисправление: система сделает это автоматически

### **Если есть ошибки в логах:**
1. Проверьте валидацию: система покажет конкретные проблемы
2. Посмотрите резервные копии: `ls trading_state_v1_6_TXB.json.backup.*`
3. Запустите мониторинг для отслеживания в реальном времени

### **Если нужно восстановить состояние:**
1. Найдите последнюю резервную копию
2. Скопируйте её: `cp trading_state_v1_6_TXB.json.backup.YYYYMMDD_HHMMSS trading_state_v1_6_TXB.json`
3. Перезапустите систему

## 🚨 Экстренные ситуации

### **Критические проблемы:**
1. **Недостаток средств** - пополните баланс
2. **Повреждение файлов** - система автоматически восстановит
3. **Большие убытки** - проверьте позиции и стоп-лоссы

### **Быстрое восстановление:**
```bash
# Остановить систему
Ctrl+C

# Запустить автоисправление
python -c "
from signalwarden_lite.core.auto_fixer import AutoFixer
fixer = AutoFixer('trading_state_v1_6_TXB.json')
result = fixer.run_auto_fix(['ADA_USDT', 'LTC_USDT', 'DOGE_USDT', 'ENA_USDT', 'HBAR_USDT', 'WIF_USDT', 'PNUT_USDT'])
print('Исправления:', result['fixes_applied'])
"

# Перезапустить систему
python start_live_trading.py --live
```
