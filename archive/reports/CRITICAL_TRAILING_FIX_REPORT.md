**Критическая ошибка:** LTC позиции закрывались с PnL ~$0 (-$0.01, $0.00, +$0.01) вместо правильного стоп-лосса

## 🔍 АНАЛИЗ ПРИЧИНЫ

### Что происходило:
1. **Трейлинг работал правильно** - обновлял SL на правильные уровни
2. **Stop-market ордера создавались с правильными stopPrice**
3. **НО!** Функция `sync_positions_from_exchange()` **ПЕРЕЗАПИСЫВАЛА** трейлинг SL!

### Корень проблемы:
В функции `sync_positions_from_exchange()` (строки 288-384):

```python
# СТАРЫЙ КОД (ОШИБОЧНЫЙ):
# Отменяем ВСЕ старые SL ордера (включая трейлинг!)
for order in open_orders:
    if order['type'] in ['stop_market', 'stop']:
        self.exchange.cancel_order(order['id'], ccxt_sym)

# Создаем новый ордер с ATR-based SL (игнорируя трейлинг!)
sl_price = entry_price - (self.sl_atr_mult * effective_atr)
new_sl_order = self.exchange.create_order(
    params={'stopPrice': sl_price}  # ← ПЕРЕЗАПИСЫВАЕТ ТРЕЙЛИНГ!
)
```

### Последовательность ошибки:
1. **Позиция открывается** с SL $113.31 (правильно)
2. **Трейлинг активируется** и улучшает SL (правильно)  
3. **sync_positions_from_exchange()** запускается каждые несколько минут
4. **Функция отменяет трейлинг stop-market ордер** ❌
5. **Создает новый ордер с исходным ATR-based SL** ❌
6. **Позиция закрывается по неправильному SL** ❌

## ✅ ИСПРАВЛЕНИЕ

### Новая логика в `sync_positions_from_exchange()`:

```python
# НОВЫЙ КОД (ИСПРАВЛЕННЫЙ):
existing_pos = self.active_positions.get(symbol)
if existing_pos and existing_pos.get('trailing_active', False):
    # Позиция уже в трейлинге - НЕ ТРОГАЕМ SL!
    logger.warning(f"🔒 {symbol}: Позиция в трейлинге - пропускаем пересчет SL")
    sl_price = existing_pos['sl_current']  # Используем трейлинг SL
else:
    # Новая позиция - рассчитываем ATR-based SL
    sl_price = entry_price - (self.sl_atr_mult * effective_atr)
```

### Ключевые изменения:
1. **Проверка трейлинга:** Если `trailing_active = true`, НЕ пересчитываем SL
2. **Сохранение трейлинг SL:** Используем `existing_pos['sl_current']`
3. **Защита от перезаписи:** Трейлинг ордера больше не отменяются при синхронизации
