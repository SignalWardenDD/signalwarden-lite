# 📁 Архив проекта SignalWarden

Этот каталог содержит архивные файлы, организованные по категориям для удобства навигации.

## 📊 Структура архива

### `backtest_reports/`
- Отчеты бэктестов в формате CSV
- Сравнительные анализы различных версий системы
- Результаты тестирования стратегий

### `backtest_trades/`
- Детальные данные о сделках из бэктестов
- Торговые журналы для анализа
- Данные для статистического анализа

### `backup_states/`
- Резервные копии состояния торговой системы
- Автоматические бэкапы `trading_state_v1_6_TXB.json`
- Состояния системы на различные моменты времени

### `reports/`
- Аналитические отчеты и документация
- Отчеты об исправлениях и улучшениях
- Руководства по использованию системы
- Результаты аудитов и тестирования

### `scripts/`
- Вспомогательные скрипты для тестирования
- Скрипты для запуска бэктестов
- Отладочные и диагностические инструменты
- Утилиты для анализа данных

## 🎯 Активные файлы

Основные рабочие файлы остались в корне проекта:
- `start_live_trading.py` - главный скрипт для запуска live торговли
- `trading_state_v1_6_TXB.json` - текущее состояние системы
- `signalwarden_lite/` - основная кодовая база
- `README.md` - основная документация
- `requirements.txt` - зависимости проекта
