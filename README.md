## Описание папок

- **archive/**: Содержит архивные версии файлов и старые данные
- **backups/**: Резервные копии важных файлов
- **data/**: Основные данные системы (исторические данные, свечи, ML данные)
- **data_files/**: Текущие файлы данных (отчеты бэктестов, состояния)
- **documentation/**: Вся документация проекта
- **reports/**: Актуальные отчеты и анализ
- **scripts/**: Утилиты, диагностические и тестовые скрипты
- **signalwarden_lite/**: Основной код торговой системы
- **tests/**: Тесты системы

## Быстрый старт

1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите живой трейдинг: `python start_live_trading.py --live`
3. Запустите в тестовом режиме: `python start_live_trading.py --paper`
4. Проверьте статус системы: `python scripts/check_system_status.py`

### Команды запуска

```bash
# LIVE торговля (реальные деньги)
python start_live_trading.py --live

# Тестовый режим (без реальных ордеров)
python start_live_trading.py --paper

# Справка по командам
python start_live_trading.py --help
```

## Основные компоненты

- **signalwarden_lite/**: Основная торговая система
