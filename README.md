# 🚀 SignalWarden Lite v1 - Modular Crypto Trading System

**Простая, модульная и проверяемая торговая система для Binance USDT-M futures**

## 📋 Описание

SignalWarden Lite v1 - это торговая система, основанная на:
- **Пробой swing-уровней** с ATR-адаптивным входом
- **Трендовый фильтр** EMA(50/200) 
- **R-ориентированный риск-менеджмент** с частичными фиксациями
- **Адаптивный трейлинг** стоп-лоссов
- **Режим рынка** на основе NATR для избежания "болота"

### Ключевые особенности:
- ✅ Модульная архитектура (легко тестировать и модифицировать)
- ✅ Честный бэктест с комиссиями и проскальзыванием
- ✅ Maker-first исполнение с TTL и market fallback
- ✅ Paper и live торговля через CCXT
- ✅ Контроль качества и лимиты

## 🎯 Целевые пары

По умолчанию система торгует следующими парами:
- ADA/USDT, DOGE/USDT, ENA/USDT, HBAR/USDT, LTC/USDT, PNUT/USDT, WIF/USDT

## ⚙️ Конфигурация

1. **API ключи**: Ключи уже настроены в `.env` файле
2. **Настройки торговли**: Основные параметры в `signalwarden_lite/config/config.yaml`

### Основные параметры:
- `risk.notional_usdt: 15` - Размер позиции в USDT
- `exchange.testnet: true` - Использовать тестнет (для безопасности)
- `symbols` - Список торгуемых пар

## 🔄 Использование

### 1. Бэктест на исторических данных

```bash
python -m signalwarden_lite.backtest.run_backtest \
  --data-dir ./data/historical_candles \
  --config ./signalwarden_lite/config/config.yaml
```

Результаты сохраняются в:
- `backtest_report.csv` - Сводка по символам
- `backtest_trades.csv` - Детальные сделки

### 2. Paper Trading (симуляция)

```bash
python -m signalwarden_lite.live.run_live \
  --config ./signalwarden_lite/config/config.yaml \
  --paper
```

### 3. Live Trading (реальная торговля)

⚠️ **ВНИМАНИЕ**: Убедитесь, что `testnet: true` в конфиге для безопасности!

```bash
python -m signalwarden_lite.live.run_live \
  --config ./signalwarden_lite/config/config.yaml
```

## 📊 Логика торговли

### Вход в позицию:
1. **Тренд**: EMA(50) > EMA(200) для лонга, EMA(50) < EMA(200) для шорта
2. **Пробой**: Цена пробивает swing high/low + ATR cushion
3. **Режим**: NATR > 0.8% (не торгуем в ultra_calm)
4. **Фильтр**: Не входим на "тонких" барах (range < 0.25*ATR)

### Управление позицией:
- **Stop Loss**: Entry ± 1.5*ATR
- **Частичные TP**: 15% @ 1R, 25% @ 2R, 60% @ 3.2R
- **Трейлинг**: Активация с 0.3R, шаг 0.3R
- **Breakeven**: При достижении 1R

### Ограничения:
- Максимум 1 позиция на символ
- Максимум 3 сделки в день на символ
- Стоп торговли после 2 убытков подряд

## 🔧 Настройка для продакшена

### Для реальной торговли:

1. **Измените в config.yaml**:
   ```yaml
   exchange:
     testnet: false  # ОСТОРОЖНО!
   ```

2. **Уменьшите риск для начала**:
   ```yaml
   risk:
     notional_usdt: 5  # Начните с малого
   ```

3. **Мониторинг**: Следите за файлом `trading_state.json`
